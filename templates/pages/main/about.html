Technologies Used

VenTory is built using modern web technologies to create a secure, responsive, and maintainable application while showcasing my current development skills.

CSRF Protection

Protects forms against cross-site request forgery attacks.

SQLAlchemy

Modern ORM used to manage and interact with the database.

Argon2-CFFI

Industry-standard password hashing for secure user authentication.

Cloudinary

Cloud-based storage and delivery for uploaded images.

Rate Limiting

Helps protect the application from abuse and brute-force attacks.

Again, this project is intended as a portfolio piece to showcase my current skills. As I continue developing it, I plan to implement additional features and technologies while expanding my knowledge and experience.
